About the project

Supporting reef awareness

ReefGuard AI explores how computer vision can make coral health information easier to access.

What is coral bleaching?

Corals can lose the algae that give them much of their color, leaving them pale or white. Bleaching can signal environmental stress and can threaten coral health.

Why early detection matters

Recognizing possible bleaching helps draw attention to reef changes and supports timely monitoring and conservation efforts.

Computer vision for monitoring

This project uses a model trained with coral image data to classify images as healthy or bleached, demonstrating one way AI can assist visual monitoring.

The model

Built with image classification

The project includes a locally stored Teachable Machine image model with the classes “healthy corals” and “bleached corals”. Images are evaluated in your browser. No accuracy or dataset-size claims are shown because those details are not included in the project files.
